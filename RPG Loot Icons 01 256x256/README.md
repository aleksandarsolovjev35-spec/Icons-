# RPG Loot Icons 01 — финальная версия 256×256

В этой папке находится утверждённый набор из **100 игровых PNG-иконок** (`icon_001.png` … `icon_100.png`). Это готовая версия с детализированной, но более полированной подачей.

## Содержимое и характеристики

| Элемент | Описание |
| --- | --- |
| `icon_001.png` … `icon_100.png` | Финальные иконки, `256×256 px`, 8-битный RGB PNG, без альфа-канала. |
| `rebuild_icons.py` | Самодостаточный скрипт, воспроизводящий обработку из исходников. |
| `SHA256SUMS` | Контрольные SHA-256-суммы финальных 100 PNG. |

Папка `../RPG Loot Icons 01` содержит восстановленные исходники с исходным размером около `146–148 px`. Она оставлена отдельно и не используется как папка результата.

> Промежуточные `512×512 px` существуют только во время обработки. Финальный пакет всегда состоит из файлов `256×256 px`.

## Утверждённый характер изображения

Обработка настроена на следующий баланс:

- мелкие элементы и фактура важнее агрессивного удаления шума;
- остаточный мелкий шум аккуратно приглушён, чтобы заливки выглядели чище;
- промежуточное увеличение до 512 px даёт более ровный, «полированный» вид;
- контуры немного контрастнее, но без жёсткой резкости, ореолов или глобального усиления контраста.

## Точная последовательность обработки

Каждая исходная иконка обрабатывается **только один раз** в следующем порядке:

1. **Мягкое цветное шумоподавление на исходном размере** с OpenCV Non-Local Means:
   ```python
   cv2.fastNlMeansDenoisingColored(
       image, None,
       h=5, hColor=6,
       templateWindowSize=7,
       searchWindowSize=21,
   )
   ```
   Небольшие пороги `h=5` и `hColor=6` сохраняют мелкие нарисованные элементы, но убирают часть цветной зернистости.

2. **Промежуточное увеличение до `512×512`**:
   ```python
   cv2.resize(cleaned, (512, 512), interpolation=cv2.INTER_CUBIC)
   ```
   Используется bicubic-интерполяция: она сохраняет непрерывные формы без искусственного перешарпа.

3. **Антиалиасинговое уменьшение до финальных `256×256`**:
   ```python
   cv2.resize(intermediate, (256, 256), interpolation=cv2.INTER_AREA)
   ```
   Этот шаг сглаживает остаточную неровность после 512 px и делает поверхность и контуры более ровными.

4. **Очень лёгкое повышение локального контраста только на контурах.** Коррекция выполняется только в канале яркости `L` пространства Lab:
   ```python
   local = cv2.GaussianBlur(L, (0, 0), sigmaX=0.85, sigmaY=0.85)
   edge_detail = L - local
   edge_mask = np.clip((np.abs(edge_detail) - 7.0) / 16.0, 0.0, 1.0)
   L = np.clip(L + 0.08 * edge_detail * edge_mask, 0, 255)
   ```
   Значение `0.08` означает лишь 8 % от локальной разницы, а плавная маска затрагивает только достаточно сильные переходы. Однородные заливки, слабая текстура и остаточный шум не усиливаются.

5. **Сохранение в PNG** с уровнем сжатия 9:
   ```python
   cv2.imwrite(path, result, [cv2.IMWRITE_PNG_COMPRESSION, 9])
   ```

### Важные ограничения

Чтобы получить тот же визуальный результат, не меняйте порядок этапов и не добавляйте следующие операции:

- не применяйте шумоподавление после увеличения;
- не заменяйте `INTER_CUBIC` / `INTER_AREA` на резкий ресемплинг;
- не используйте обычный `sharpen`, unsharp mask или глобальное повышение контраста;
- не обрабатывайте уже обработанные PNG повторно — всегда начинайте с исходников из `RPG Loot Icons 01`.

## Как воспроизвести результат

### 1. Установить зависимости

Нужны Python 3.10+ и OpenCV. Проверенная версия OpenCV — `4.10.0.84`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
python3 -m pip install "opencv-python-headless==4.10.0.84" numpy
```

### 2. Запустить скрипт из корня репозитория

Команда ниже сохраняет новую копию результата в отдельную папку и не изменяет исходники:

```bash
python3 "RPG Loot Icons 01 256x256/rebuild_icons.py" \
  --input "RPG Loot Icons 01" \
  --output "/tmp/RPG Loot Icons 01 256x256 rebuilt"
```

Скрипт должен сообщить об обработке 100 файлов. Укажите `--overwrite`, только если целевая папка уже содержит PNG с такими же именами и их действительно нужно заменить.

### 3. Проверить финальный пакет

Проверка поставленных файлов по контрольным суммам:

```bash
cd "RPG Loot Icons 01 256x256"
sha256sum -c SHA256SUMS
```

Ожидаемый результат — `OK` для всех 100 файлов. Чтобы сравнить заново собранный результат с контрольными суммами, выполните команду из новой выходной папки и передайте ей абсолютный путь к этому файлу `SHA256SUMS`.
